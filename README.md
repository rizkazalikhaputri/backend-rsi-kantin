# REST API Sistem Review Kantin

Tugas 2 Praktikum Rekayasa Sistem Informasi — REST API dengan CRUD dan integrasi database SQL Server.

## Teknologi
- Express.js
- SQL Server (mssql driver)
- dotenv, cors

## Struktur Database
7 tabel: USERS, STALLS, MENU_ITEMS, REVIEWS, LIKES, FLAGS, AUDIT_LOGS.
